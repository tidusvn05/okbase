# okbase-search

Semantic search and retrieval for okbase bundles (needs an embedder from okbase-embed).

Part of [okbase](https://github.com/tidusvn05/okbase), a Rust toolkit for markdown knowledge
bundles in the [Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format).
okbase is a community project, not affiliated with Google.

## Install

```sh
cargo add okbase-search
```

See the [usage guide](https://github.com/tidusvn05/okbase/blob/main/docs/usage.md),
[API documentation](https://docs.rs/okbase-search) and
[repository](https://github.com/tidusvn05/okbase) for examples and supported features.
