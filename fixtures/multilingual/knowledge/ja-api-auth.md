# パートナーAPIの認証方式

パートナーAPIへのアクセスには、OAuth 2.0のクライアントクレデンシャル方式を使用します。管理画面で発行したクライアントIDとシークレットを /oauth/token に送信すると、アクセストークンが返されます。トークンの有効期限は1時間で、リフレッシュトークンは発行されませんので、期限切れ後は再度取得してください。各リクエストの Authorization ヘッダーに Bearer トークンを付与します。シークレットは90日ごとのローテーションを推奨しています。
