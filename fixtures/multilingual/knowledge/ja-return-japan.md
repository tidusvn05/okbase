# 日本公式オンラインストアの返品

ヒカリ日本公式オンラインストアでご購入の商品は、お届けから8日以内であれば返品を受け付けます。お客様都合の返品は未開封・未使用の商品に限り、返送料はお客様のご負担となります。初期不良の場合は、送料当社負担で新品と交換いたします。返品をご希望の際は、必ずマイページから返品申請を行い、発行された返品番号を箱に記入してお送りください。事前のご連絡がない返品はお受けできません。
