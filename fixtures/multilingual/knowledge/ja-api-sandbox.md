# サンドボックス環境の利用

本番環境に接続する前に、サンドボックス環境 sandbox.api.hikari.example で動作確認を行ってください。サンドボックス用のAPIキーは管理画面から即時に発行できます。レート制限は本番より低く、1分あたり60リクエストまでです。作成した注文データが実際に出荷されることはなく、毎週日曜日の深夜にすべてリセットされます。決済のテストには、ドキュメントに記載されたテスト用カード番号をご利用ください。
