# Rice cooker error codes

Hikari rice cookers display error codes on the front panel. E1 means the temperature sensor is disconnected; unplug the cooker and contact service. E2 indicates overheating, usually because the inner pot is empty or not seated correctly. E3 means the lid is not fully closed. E4 is a power voltage problem. If an error persists after restarting, stop using the appliance and request a repair.
