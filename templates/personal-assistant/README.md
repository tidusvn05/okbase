# Personal assistant knowledge

Keep durable preferences, daily context and project memory usable across assistant sessions.

For: individual, developer, leader.

Browse [the bundle](bundle/index.md) and [getting started](bundle/guides/getting-started.md) before initializing.

```sh
okbase -b ./kb init --template personal-assistant --print
okbase -b ./kb init --template personal-assistant
```

Domain records are fictional examples. Replace them with verified information, extend the type
schemas and vocabulary, and run `okbase lint --level L2` after editing. Workflow guides describe
host-authorized work; they do not execute external actions.
