# Database server db-01

> Fictional example: replace this record with your own information before relying on it.

## Hosted service
The atlas-db PostgreSQL service runs on db-01 in production.
The platform-team owns database availability and recovery. This demo does not contain connection strings, passwords, actual backup files or a validated restore command.
## Impact
The [API](../services/api.md) requires the database for reads and writes; the [worker](../services/worker.md) reads outbox events from it. Consult the [database service record](../services/database.md) before planning changes.
