# First week onboarding

> Fictional example: replace this record with your own information before relying on it.

## First week
Start by reading the team charter, then locate the owner of one API and one operational dependency.
Request project access through the approved process. Confirm a local development smoke test using the real repository instructions; this bundle does not contain the application.
## Checkpoint
Explain one request path and identify where to ask for missing information. Review the [ownership map](../team/ownership.md), [access policy](../policies/access.md), and [working agreement](../policies/communication.md).
