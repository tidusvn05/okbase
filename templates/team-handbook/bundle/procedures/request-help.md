# Request help or unblock work

> Fictional example: replace this record with your own information before relying on it.

## Request format
Include the goal, attempted steps, observed result, missing input, requested owner and impact.
Link the relevant document or task and describe what would unblock the work. Use redacted evidence; do not attach secrets or unrelated personal context.
## Routing
Check the [ownership directory](../team/ownership.md). Prepare the request in the user's chosen channel; send it only through an authorized host tool.
For access-related work, use the [access policy](../policies/access.md).
